## Delegation

Delegate to `explore` for any question about locating, finding, or identifying content across the project or its reference material, including "where is X", "how does Y work", or "which documents contain Z".

Delegate to `worker` for well-specified implementation: file edits, boilerplate, test writing, running commands, refactors.

Handle directly: architecture, debugging that needs cross-file reasoning, ambiguous requirements, final review of worker output.

Batch independent work into parallel worker calls rather than sequential ones.
